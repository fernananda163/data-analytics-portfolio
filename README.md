### 📈 [MarketPulse Analytics](https://github.com/fernananda163/marketpulse-analytics-)

**Marketing Performance Analysis | Python**

The project evaluates revenue, advertising efficiency, conversion performance, and marketing trends to identify opportunities for better business decisions.

**Skills & Tools:**

- NumPy
- Matplotlib
- Data Cleaning
- KPI Analysis
- Data Visualization
- Business Insights

**Key Metrics:** CTR, Conversion Rate, CPC, CPA, and ROAS.

### 🛒 [ShopScope SQL Analytics](https://github.com/fernananda163/shopscope-sql-analytics-)

**E-commerce Sales Analysis | SQL**

ShopScope is a compact SQL analytics project focused on understanding product sales and revenue performance for an e-commerce business.

The analysis identifies top-performing products and categories, compares revenue with sales volume, and calculates key sales metrics.

**Skills & Tools:**
- SQL
- SQLite
- Python
- Pandas
- Matplotlib
- Data Aggregation
- Sales Analysis
- Business Insights

**Key Metrics:** Total Revenue, Units Sold, Revenue by Product, Revenue by Category, and Average Order Value.
